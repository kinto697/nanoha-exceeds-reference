Chapter 02
👤 核心角色档案
按联动优先级排列。奈叶和菲特是粉丝认知度的核心，诗奈是本作正式女主角。

高町奈叶

Takamachi Nanoha · CV：田村由香里（20年未更换）
暴君白色恶魔以炮交友全力全开

本作中13岁，隶属联合国危险生物调查机关EXCEEDS担任前线调查员。性格固执、正义感爆棚、不服输。战斗哲学：先把你轰趴再跟你讲道理。

本作新设计：全新防护服（Barrier Jacket），身材更修长纤细。旭日之心（Raising Heart）魔导器保留。第三弹主视觉图中与菲特并肩立于烈焰之前。

粉丝认知：系列灵魂人物，20年积累核心粉丝群。"SLB（星光爆裂）"= 地图炮代名词。"魔法少女最凶最恶"代表。

菲特·T·哈洛温

Fate Testarossa Harlaown · CV：水树奈奈（兼OP演唱）
宠妃金色闪电雷光战斧奈叶的「丈夫」

奈叶的伴侣（官方设定：菲特 = 奈叶的"丈夫"）。初登场冷漠孤独，被奈叶"以炮交友"收服后变得温柔爱操心。

本作新设计：防护服回归全黑底色初代风格，发型为单马尾（区别于以往双马尾）。巴鲁迪修（Bardiche）魔导器保留。OP《CRIMSON BULLET》由水树奈奈演唱。

久濑诗奈

Kuze Shiina · CV：橘杏咲
EXCEEDS新主角猎人少女火焰魔炮魔人之力继承者

本作正式女主角。离岛高中生，以驱除侵略种为业的猎人。唯一愿望是与义妹雪奈平静度日。

🔑 第1集关键剧情：被敌方"魔人"袭击，妹妹雪奈为保护她被吞噬，临终前将魔人之力全部转移。诗奈以觉醒的Fire Magic Blast（火焰魔炮）消灭敌方。此后前往本岛，遇到EXCEEDS调查员奈叶。

久濑雪奈

Kuze Setsuna · CV：日高里菜
义妹魔人牺牲与传承诗奈的力量之源

诗奈的义妹（无血缘），真实身份为"魔人"。诗奈早已察觉她的异常，仍视她为最珍爱的妹妹。

🔑 第1集关键剧情：为保护姐姐解放魔人之力，肉体被敌方吞噬，但力量完整转移给诗奈。此后可能以精神体／回忆／力量残留形式持续出现。

联动意义：可作为诗奈觉醒演出的情感trigger（幻影/声音），姐妹情深是诗奈角色弧光的核心。

💕 奈叶×菲特 — 联动的最大情感卖点
这对CP是系列最核心的资产，粉丝最在意的内容。联动中任何涉及两人互动的设计都必须尊重这层关系。

菲特·T·哈洛温

巴鲁迪修 · 雷光战斧

关系演变：敌人 → 被SLB轰入海中 → 挚友 → 伴侣 → 共同抚养女儿薇薇欧
官方设定：菲特 = 奈叶的「丈夫」 · 奈叶 = 菲特的「要守护的人」 · 两人+薇薇欧 = 一家三口
CP名：奈菲（なのフェイ）—— 20年积累的最强粉丝群体
核心梗：「以炮交友」—— 全力轰击 → 对方臣服 → 成为终身挚友／家人

💡 联动设计要点

奈叶和菲特的双人互动是皮肤／卡面／PV的最高价值内容。背靠背、牵手、并肩飞行、对视微笑——都是粉丝最吃的内容。避免塑造成普通队友关系，要体现"家人／伴侣"的亲密感。建议至少设计一个明确的奈菲双人互动元素（双人胜利pose / 双人觉醒演出 / 特殊连携技）。

Chapter 06
🎬 星之翼联动PV脚本框架
考虑3D制作力限制的6段式分镜。核心策略：70%特效 + 20%镜头 + 10%角色动画。

⚠️ 制作约束假设

制作力不高 = 避免复杂角色动画（表情细腻变化、长段对话口型）、避免大量新骨骼绑定（斗篷物理、头发大幅飘动）、优先使用游戏内已有动作系统 + 特效增强。用强pose + 镜头调度 + 特效弥补动画复杂度不足。

1

Opening — 世界观建立（8-12秒）

  • 镜头：黑暗废墟远景 → 侵略种剪影压迫 → 镜头快速推进至瑞穗国
  • 低成本要点：静态场景 + 慢速camera push + 粒子特效（火星/灰烬），不需要角色动画
  • 音效设计：沉重低音 + 警报/怪兽嘶吼 → 突然静音
  • 字幕："30年前，世界濒临毁灭。"
2

诗奈登场 — 新主角亮相（10-14秒）

  • 镜头1：火焰魔炮从屏幕一侧轰出（特效为主，角色只需一个发射pose）
  • 镜头2：诗奈半身特写，眼神坚定，火焰魔力周身缠绕（静态pose + 特效环绕）
  • 镜头3：雪奈的透明幻影在诗奈身后一闪而过（半透明模型 + 发光shader）
  • 字幕："我只是想保护……唯一的家人。"
3

⭐ 奈叶&菲特登场 — 情怀引爆（12-18秒）核心段落

  • 镜头1：樱花色魔法阵在屏幕中央展开 → 奈叶从阵中飞出剪影（逆光，轮廓 + 光翼特效）
  • 镜头2：金色雷光一闪 → 菲特高速突进侧影，巴鲁迪修展开巨镰形态
  • 镜头3：奈叶菲特背靠背经典pose（静态双人 + 镜头慢速环绕），樱粉/金色魔力交织
  • 镜头4：快速切镜 — 奈叶SLB蓄力特写（旭日之心展开 + 魔法阵层叠）、菲特雷光缠绕格斗姿态
  • 字幕："高町奈叶。菲特·T·哈洛温。EXCEEDS调查员。"
4

战斗高潮 — GVG风格动作展示（10-15秒）

  • 镜头1：三人编队飞行（诗奈/奈叶/菲特并排，侧拍平移，不需要复杂动画）
  • 镜头2：快速连切 — 奈叶Axel Shooter齐射 → 菲特巨镰斩击 → 诗奈火焰炮击
  • 镜头3：奈叶SLB全屏轰击！镜头拉远展示爆炸范围（90%靠特效）
  • 镜头4：侵略种/魔人被击破的崩溃效果
5

觉醒/大招展示 — 星能爆发映射（6-10秒）

  • 奈叶觉醒：Exceed Mode — 旭日之心金色展开，魔力光爆发，魔法阵从脚下扩散（站桩+超大特效）
  • 菲特觉醒：Sonic Form — 全身雷光缠绕，速度线 + 瞬移残影效果
  • 诗奈觉醒：魔人之力解放 — 火焰柱冲天，眼睛变色/纹路发光
  • 低成本要点：觉醒 = 站桩pose + 超大特效 + 镜头震动。3D PV性价比最高的段落。
6

Ending — Logo + 联动信息（6-8秒）

  • 镜头：三人站姿集合 → 星之翼Logo与EXCEEDS Logo并排 → 奈叶伸出手（呼应"以炮交友"→"以手交友"）
  • 字幕："星之翼 × 魔法少女奈叶 EXCEEDS Gun Blaze Vengeance" + 联动日期

⚠️ 联动风险与注意事项

🔴 风险1：动画刚开播，内容不完整

诗奈的完整能力、最终形态、关键剧情转折均未公开。若联动在9月前上线，建议奈叶+菲特为主、诗奈为辅的策略——奈叶菲特有20年积累，诗奈只做基础展示。

🔴 风险2：版权范围限制

授权仅覆盖EXCEEDS，不能使用系列前作角色设计。但奈叶菲特的核心性格、关系、经典pose属于角色本质特征。建议所有视觉设计严格以EXCEEDS官方公开的视觉图/动画截图为准。

🔴 风险3：粉丝期待管理

奈叶系列粉丝对奈菲CP有极高情感投入。若两人互动被做成"普通同事"，会引发粉丝强烈不满。务必至少设计一个明确的双人互动元素。

🟢 建议：诗奈×雪奈 姐妹线作为第二情感轴

除了奈菲CP，"诗奈×雪奈"的姐妹情深也非常有力。雪奈虽第1集就死了，但她的牺牲和力量传承是诗奈一切行动的动机。PV中用雪奈的幻影/声音作为诗奈觉醒的trigger，同样催泪——姐妹情 + 奈菲情 = 双情感线并行。
